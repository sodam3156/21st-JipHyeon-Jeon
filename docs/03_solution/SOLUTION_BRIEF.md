# 솔루션 개요

## 가치 제안

회동(會同)은 모임 제안자가 참여자 조건을 한 번에 모으고, 세종의 공간·교통 조건을 결합한 실행 가능한 대안 3개를 비교해, 근거가 보이는 한 가지 안으로 합의하도록 돕는 AI 모임 설계 서비스입니다.

## 핵심 사용자 흐름

1. 제안자가 모임 목적, 인원, 시간 범위, 예산, 출발 지점을 입력합니다.
2. 참여자는 링크에서 가능 시간과 선호·회피 조건을 답합니다.
3. 시스템은 충돌 조건과 반드시 지켜야 할 제약을 정리합니다.
4. AI가 검증된 장소·교통 데이터 안에서 대안 3개를 구성합니다.
5. 집현전 역할들이 각 대안의 이동, 비용, 취향, 현실성을 짧게 설명합니다.
6. 사용자는 조건 가중치를 바꾸거나 질문해 대안을 재정렬합니다.
7. 최종안을 공유 가능한 일정 카드로 확정합니다.

## MVP 범위

### P0 — 데모에 반드시 필요

- 모임 조건 입력
- 4–8명 참여자 조건 수집 또는 데모용 사전 입력
- 충돌 조건 요약
- 데이터에 근거한 대안 3개 생성
- 대안별 시간·비용·이동·선호 충족도 비교
- 사용자의 우선순위 변경
- 최종 일정 카드 확정

### P1 — 시간이 남으면

- 참여자별 링크 응답
- 대안 투표와 댓글
- 지도 경로 미리보기
- 집현전 캐릭터의 역할별 설명 애니메이션

### 제외 범위

- 세종 전체 생활 정보 포털
- 숙박·부동산·의료·행정 추천
- 실제 결제와 예약
- 완전 자율 다중 에이전트 인프라
- 장기 커뮤니티와 친구 매칭
- 모든 지역으로의 확장

## AI가 맡는 일

- 자연어 조건을 구조화합니다.
- 충돌하는 조건을 탐지하고 누락 정보를 질문합니다.
- 검증된 후보 데이터에서 조건에 맞는 조합을 만듭니다.
- 대안의 장단점과 선택 근거를 읽기 쉽게 설명합니다.
- 사용자가 가중치를 바꿀 때 대안을 재평가합니다.

AI는 장소 존재 여부, 영업시간, 교통편을 지어내지 않습니다. 해당 값은 검증된 데이터나 명확히 표시된 데모 데이터에서만 사용합니다.

## 차별점 가설

검색 결과를 나열하는 서비스가 아니라, 여러 사람의 상충 조건을 하나의 의사결정 문제로 정리하고 비교 가능한 대안과 합의 근거를 제공한다는 점입니다.

## 데모 성공 장면

“금요일 저녁, 6명, 1인 2만 원 이하, 차량 없음, 한 명은 21시 전에 귀가”라는 입력이 들어오면, 시스템이 불가능한 조합을 설명하고 실행 가능한 3개 안을 제시합니다. 사용자가 ‘이동 피로’를 더 중요하게 바꾸면 순위와 설명이 달라지고, 최종 일정 카드가 만들어집니다.
