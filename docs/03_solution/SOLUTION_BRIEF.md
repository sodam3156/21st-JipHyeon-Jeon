# 보관된 솔루션 개요 — IDEA-001

> 이 문서는 인사이트 게이트를 만들기 전에 `IDEA-001 회동(會同)`을 먼저 구체화했던 역사적 기록입니다. 현재 설계 기준, 선택 후보, P0 범위가 아닙니다.

## 보관 이유

- 최근 실제 모임 조율 행동·손실·기존 대안 실패가 확인되지 않았습니다.
- OPP-002의 문화 콘텐츠 부족·발견 실패와 모임 조율 실패의 연결이 입증되지 않았습니다.
- Gate 2와 Gate 3을 통과하지 않은 seed를 솔루션부터 확장하면 이후 근거가 아이디어에 맞춰질 위험이 있습니다.

## 재개 조건

IDEA-001은 아래 조건을 모두 충족할 때 새 `SOL-ID`로 다시 설계합니다.

1. 연결 기회가 Gate 2를 통과합니다.
2. IDEA-001이 Portfolio 진입 조건 8개와 Gate 3를 통과합니다.
3. 독립 반론에서 즉시 탈락 조건에 걸리지 않습니다.
4. 제품 책임자가 솔루션 설계 진행을 승인합니다.

이전 세부 기능·데모 흐름은 현재 비교에 사용하지 않습니다. 필요한 경우 Git 이력에서만 확인합니다.
