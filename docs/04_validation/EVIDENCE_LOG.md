# 검증 근거

이 문서는 문제·고객·솔루션 가설을 지지하거나 반박하는 근거의 정본입니다. 숫자나 인용을 만들지 않으며, 한 사람의 의견을 시장 전체의 사실로 일반화하지 않습니다.

## 근거 등급

| 등급 | 유형 | 예시 |
|---|---|---|
| A | 직접 행동·관찰 | 최근 실제 조율 과정, 사용 로그, 현장 테스트 |
| B | 다수 인터뷰·실험 | 동일 패턴의 인터뷰, 프로토타입 과제 성공률 |
| C | 공식 데이터·원문 | 공공데이터, 공식 교통·시설 정보 |
| D | 전문가 의견·2차 자료 | 멘토 피드백, 기사, 블로그 |
| E | 팀 내부 추정 | 아이디어 회의, 개인 경험 |

## 현재 근거 공백

- 최근 실제 모임 조율 사례
- 문제 발생 빈도와 결정 소요 시간
- 모임 지연 또는 무산의 직접 원인
- 기존 도구의 구체적 실패 지점
- AI 추천에 대한 신뢰와 입력 부담
- 데모 범위에서 사용할 장소·교통 데이터의 정확성
