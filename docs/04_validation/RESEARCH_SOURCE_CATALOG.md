# 조사 원천 목록

이 문서는 `planning.insight-ledger`에 사용한 원천과 사용할 수 있는 범위를 기록합니다. 원천의 분량이나 항목 수는 근거의 강도를 뜻하지 않습니다.

## 사용 원칙

- 원문을 직접 읽은 자료만 `inspected`로 표시합니다.
- 제목·설명·메타데이터만 확인한 자료는 세부 주장의 확정 근거로 쓰지 않습니다.
- 해커톤 수상 회고는 전략 가설을 만드는 보조 근거이며 특정 고객 문제의 존재를 증명하지 않습니다.
- 백엔드·AI 개발 자료는 구현 안전장치의 근거이며 아이디어의 시장성이나 세종 시민의 고통을 증명하지 않습니다.
- 문제은행의 A·B 등급은 각 문제 항목의 원출처 품질을 뜻합니다. 누적본 전체를 하나의 A등급 근거로 취급하지 않습니다.
- 최신성이 필요한 규정, 요금, API, 데이터 접근성은 사용 직전에 공식 원문으로 다시 확인합니다.

## 원본 접근 상태

- `RS-PB-001`의 정본은 별도 Library의 `document_id=sejong-ax.problem-bank`로 관리됩니다.
- 나머지 조사 원본은 이번 분석에 첨부된 외부 파일이며 이 저장소에는 복제하지 않았습니다.
- 이 저장소의 인사이트·원천 요약은 협업을 위한 파생 기록입니다. 원문 재감사가 필요한 팀원이나 AI는 원본 파일을 제공받은 뒤 실제 읽은 범위를 새 실행 기록에 남겨야 합니다.
- 원본에 접근하지 못한 상태에서는 기존 인사이트를 사용할 수는 있지만, 원문을 다시 확인했다고 표현하거나 세부 인용을 새로 만들 수 없습니다.
- 파일 크기와 SHA-256은 `validation.source-snapshot-manifest`에서 확인합니다.
- 원본 접근이 없는 상태에서는 기존 claim의 범위를 넘어 새 기회 영역이나 수치로 확장하지 않습니다.
