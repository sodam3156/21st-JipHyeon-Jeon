| 항목 | 제안 |

| 고객 | 세종 거주, 6–36개월 자녀를 가정양육하는 보호자 |

## 기존 회동 가설의 위치

20–24세 고려대 세종캠퍼스 무차량 대학생 중 4–8명의 취미·문화 모임 제안자가 참여자 시간·취향·예산과 공간·교통 제약을 맞추기 어렵다는 가설은 `IDEA-001`, `seed` 상태입니다.

- 장점: 구체 고객을 가정한 검증 가능성, 집현전 표현과 합의 UX
- 공백: 최근 행동, 발생 빈도, 손실, 기존 대안 실패의 직접 근거
- 주의: 문화 콘텐츠 부족·발견 실패 문제와 모임 조율 문제를 같은 것으로 간주하지 않음
- 영향: 이전 솔루션 초안은 보관됐고 PRD는 선택 전까지 의도적으로 비워 둠

## 확정된 방향

- 인사이트 → 기회 영역 → 최근 행동 검증 → 아이디어 → 반론 → 솔루션·실험 → 사람 결정 순서로 진행합니다.
- 관광객, 이주민, 대학생을 동시에 주요 고객으로 삼지 않습니다.
- 광범위한 세종 생활 정보 통합 서비스는 제외합니다.
- 세종 요소가 판단 결과를 바꾸지 않으면 지역 적합성이 약한 것으로 봅니다.
- 멀티 관점은 독립된 책임과 사용자 가치가 있을 때만 사용합니다.
- AI 에이전트는 메인 아이디어를 선택하거나 정본을 자동 병합하지 않습니다.
- 기술 조사와 고객 문제 근거의 용도를 분리합니다.
