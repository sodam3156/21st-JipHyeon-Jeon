## 현재 작업 가설

20–24세 고려대 세종캠퍼스 무차량 대학생 중 4–8명의 취미·문화 모임을 처음 제안하거나 운영하는 학생은, 참여자 시간·취향·예산과 세종의 공간·교통 제약을 한 번에 맞추기 어려워 모임 확정이 늦어지거나 무산된다.

## 확정된 방향

- 고객 → 문제 → 해결 가능 범위 → 기술 → UX 순서로 기획합니다.
- 관광객, 이주민, 대학생을 동시에 잡지 않습니다.
- 광범위한 세종 생활 정보 통합 서비스는 MVP에서 제외합니다.
- 멀티 관점과 토론 시각화는 유지하되 실제 가치와 구현 가능성으로 범위를 결정합니다.
- 해커톤 평가는 데모에서 문제와 해결의 연결이 보이도록 준비합니다.
