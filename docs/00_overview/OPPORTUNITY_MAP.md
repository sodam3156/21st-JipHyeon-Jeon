# 기회 영역 지도

이 문서는 솔루션 이름을 정하기 전에 세종의 문제 원형을 비교하는 정본입니다. `D-010`(2026-07-25)에서 OPP-005가 메인 방향으로 확정됐으며, Gate 2 정식 검증은 waived 상태로 계속 진행 중입니다.

## 평가 표기

- `높음`: 현재 자료에서 반복되거나 교차 근거가 있음
- `중간`: 가능성은 있으나 직접 행동·데이터 접근 등 핵심 공백이 있음
- `낮음`: 현재 근거 또는 실행 조건이 부족함
- `위험`: 안전·책임·데이터 의존이 크므로 범위를 강하게 제한해야 함

등급은 시장 규모나 성공 확률이 아니라 **다음 검증의 우선순위**입니다.

상태는 `proposed`, `explore`, `gate2-ready`, `parked`, `rejected`, `selected` 중 하나를 사용합니다.

## OPP-001 — 정시 도착 중심 무차량 이동 조정

### 기회 문장

정해진 출근·등교·진료 시각이 있는 무차량 이용자가 제한된 버스·셔틀·특별교통수단 안에서 탑승 가능성과 대체안을 미리 판단하도록 돕습니다.

### 왜 검토하는가

- 문제 강도와 반복성이 가장 강한 군입니다.
- 시간표, 출발지, 근무조, 환승, 수요를 함께 다루므로 AI 역할이 비교적 자연스럽습니다.
- 입력 전후에 `지각 위험 → 실행 가능한 출발안` 상태 변화가 보입니다.

### 치명 가정

- 공개·제보 데이터만으로도 의미 있는 탑승·도착 위험을 계산할 수 있는가?
- 사용자가 기존 지도·알림보다 나은 결정을 하는가?
- 실제 배차를 바꿀 수 없는 상태에서도 충분한 가치가 있는가?

### 48시간 검증

- SJ-P-0026 고객 3명과 SJ-P-0006 또는 SJ-P-0001 고객 3명의 최근 통근·통학 사례를 받습니다.
- 실제 시간표 10건으로 현재 경로와 제안 경로의 지각 위험·조기 출발 시간을 비교합니다.

## OPP-002 — 지역 문화 수요를 콘텐츠 기획·실행으로 전환

### 기회 문장

세종 청년의 미충족 장르·시간·동행·예산 수요를 모아, 단순 추천이 아니라 실제 열 수 있는 소규모 콘텐츠 기획안과 참여 결정을 만듭니다.

### 왜 검토하는가

- SJ-P-0022, SJ-P-0023, SJ-P-0024는 문제은행의 A등급 자료입니다.
- 대학생과 문화 활동 관련 검증 대상을 48시간 안에 모집할 수 있는지 우선 확인합니다.
- 해커톤 대주제인 AI 콘텐츠 제작과 직접 연결할 수 있습니다.

### 치명 가정

- “콘텐츠가 부족하다”가 아니라 구체 장르·시간대·참여 장벽이 반복되는가?
- 수요 집계가 행사 추천보다 실제 콘텐츠 생성·개최 결정을 개선하는가?
- 운영자 또는 소상공인이 결과물을 다음 행동에 사용할 수 있는가?

### 48시간 검증

- 최근 3개월 내 세종 밖으로 문화 원정을 간 청년 5명의 행동을 확인합니다.
- 운영자 2명에게 같은 수요 데이터를 주고 AI 기획안이 장소·시간·홍보 결정을 바꾸는지 봅니다.

## OPP-003 — 대형행사 종료 분산 귀가·출차 조정

### 기회 문장

어린 자녀·짐을 동반한 가족 방문객이 행사 종료 직후 한꺼번에 출차하지 않고, 구역별 대기·이동·대체교통을 비교해 귀가 시간을 줄이도록 돕습니다.

### 강점과 공백

- 고객·상황·손실이 매우 구체적이고 데모 장면이 강합니다.
- 행사일에만 발생해 재사용 빈도가 낮을 수 있습니다.
- 주차구역·차량 흐름·신호 데이터가 없으면 시뮬레이션임을 명시해야 합니다.

## OPP-004 — 공공서비스 실행 라우터

### 기회 문장

고령자·청소년·외국인 주민이 자신의 조건을 확인한 뒤 필요한 서류, 담당기관, 기한과 다음 행동까지 끊김 없이 이어가도록 돕습니다.

### 강점과 공백

- 다국어, 자격, 서류, 기관 인계라는 역할 경계가 명확합니다.
- 범위를 “모든 정착 정보”가 아니라 의료비 지원이나 이응패스 등록 같은 대표 사건 하나로 줄여야 합니다.
- 규정 최신성과 개인정보 처리 때문에 근거 시점·중단·사람 인계가 제품 기능이어야 합니다.

## OPP-005 — 6–36개월 비정형 돌봄의 공식 시간제보육 실행 연결

### 검증용 고객·사건

세종에 거주하며 6–36개월 자녀를 가정양육하는 보호자가 갑작스러운 평일 2–4시간 돌봄 공백을 겪고, 진료·근무·필수 일정 전까지 공식 시간제보육의 조건을 확인해 신청 또는 전화라는 다음 행동을 정해야 하는 사건입니다.

### 바뀐 문제 해석

- 해결 대상은 시설 정보의 부재가 아니라 연령·시간·등록·준비물·신청 경로의 분산입니다.
- 공식 서비스가 이미 있으므로 “시설을 찾아주는 AI”는 차별점이 아닙니다.
- 실제 자리가 없는 구조적 공급 부족과, 정보·절차 단절 때문에 행동이 늦는 조정 손실을 분리합니다.
- 실시간 가용성과 예약 성공을 확인할 공식 연동이 없으면 반드시 `확인 불가`로 남기고 기관으로 인계합니다.

### 현재 판정

`selected` — `D-010`(2026-07-25, accepted)에서 제품 책임자가 Gate 2 정식 검증 전에 메인 후보로 확정했습니다(`governance.gate-log`에 waived, 만료 2026-08-11). 기존 OPP-001–003 비교군은 `parked`로 전환했습니다. `X-006` 48시간 challenger 검증(이슈 #3)은 이 확정을 되돌릴 수 있는 근거로 계속 진행합니다.

### 치명 가정

- 보호자가 공급 부재가 아니라 조건·절차 분산 때문에 반복 검색·전화와 일정 손실을 겪는가?
- 비식별 최소 입력만으로 공식 다음 행동을 정확히 좁힐 수 있는가?
- 운영자가 반복 오문의 유형과 갱신 가능한 공식 필드를 확인하는가?
- 실시간 빈자리 없이도 실행카드가 기존 공식 웹 탐색보다 완료시간과 오접수를 줄이는가?

### 안전 경계

비공식 돌보미 매칭, 시설 품질·안전 순위, 의료·아동안전 판단, 아동 식별정보·상세주소·건강정보 수집, 실시간 빈자리·예약 성공 주장을 금지합니다.

## OPP-006 — 공유 자원 오류 복구

앱 장애·GPS 오류·주차면·충전 순번 문제에서 `오류 탐지 → 증거 보존 → 대체 행동 → 책임 주체 연결`을 하나의 흐름으로 다룹니다. 실제 상태 API 없이도 오류 복구 흐름은 시연할 수 있지만, 실시간 빈자리나 반납 완료를 사실처럼 표현하면 안 됩니다.

## OPP-007 — 지역 수요·공급 연결

청년의 역외 문화·소비와 저유동 상권을 함께 볼 수 있지만, “추천이 매출을 늘린다”는 인과는 현재 근거가 없습니다. 특정 상권·업종·시간대를 좁히고 방문 전환이나 행사 참여 같은 가까운 지표부터 검증합니다.

## 현재 우선 비교군

`D-010`(2026-07-25) 이후 메인 방향은 **OPP-005 (6–36개월 비정형 돌봄의 공식 시간제보육 실행 연결)** 로 확정됐습니다.

기존 1차 비교군이었던 아래 세 영역은 `parked`로 전환했습니다.

1. OPP-001 정시 도착 중심 무차량 이동 조정
2. OPP-002 문화 수요 기반 콘텐츠 기획·실행
3. OPP-003 대형행사 종료 분산 귀가·출차 조정

이 세 영역은 재검토 시 다시 우선 비교군에 넣을 수 있으며, 판정 근거는 `governance.gate-log`에서 유지합니다.

## 다음 게이트

기회 영역은 다음 조건을 모두 만족하면 아이디어 생성 단계로 이동합니다.

- 기회를 지지하는 인사이트의 개별 Gate 1 판정이 `passed` 또는 `waived`
- 고객 속성·장소·촉발 시각·실패 행동의 구체성
- 대상 고객의 최근 실제 행동 또는 동등한 직접 관찰 3건 이상
- 기존 대안과 실패 지점
- 측정 가능한 시간·비용·오류·포기 손실 중 하나
- 해결 가능한 부분과 구조적 공급 부족의 분리
- 사용할 수 있는 최소 데이터와 결측 처리
- AI가 바꾸는 판단 또는 결과물
- 3분 발표 안의 90초 핵심 데모 상태 변화
- 치명 가정과 사전 성공·실패 기준을 가진 48시간 실험 등록
