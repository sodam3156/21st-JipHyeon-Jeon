# 문제 정의

## 한 문장 문제

우리는 **20–24세 고려대 세종캠퍼스 무차량 대학생 중 4–8명의 취미·문화 모임을 처음 제안하거나 운영하는 학생**이 **수업이나 활동 중 새 모임의 일정을 정하는 상황**에서 반복적으로 겪는 **참여자 시간·취향·예산과 세종의 공간·교통 제약을 동시에 맞추지 못해 결정이 지연되거나 모임이 무산되는 문제**를 검증한다.

## 문제 구조

| 요소 | 현재 가설 | 필요한 근거 |
|---|---|---|
| 고객 | 20–24세 고려대 세종캠퍼스 무차량 대학생 모임 제안자 | 실제 모집 가능성과 최근 행동 |
| 상황 | 4–8명 취미·문화 모임을 처음 정할 때 | 발생 빈도와 결정 소요 시간 |
| 핵심 문제 | 여러 제약을 한 번에 비교하기 어렵다 | 무산·지연 사례와 원인 |
| 결과 | 채팅 왕복, 피로, 특정인 의존, 모임 취소 | 비용·시간·감정 영향 |
| 기존 대안 | 단체 채팅, 설문, 지도·SNS 검색, 총무 개인 판단 | 대안별 미충족 지점 |

## 문제가 중요하다고 보는 이유

- 모임 성립 전에 조율 비용이 발생해 실제 경험까지 도달하지 못할 수 있습니다.
- 차량이 없는 학생은 거리보다 대중교통 시간과 막차, 환승이 결정에 크게 작용할 수 있습니다.
- 공간, 이동, 예산을 각기 다른 앱에서 확인하면 비교와 합의가 분리됩니다.

위 세 문장은 아직 일반화할 수 없는 가설입니다. 실제 인터뷰와 행동 자료로 검증해야 합니다.

## 문제에서 제외하는 것

- 세종의 모든 생활 정보를 한곳에 모으는 문제
- 관광객 전체의 여행 일정 문제
- 단순 친구 추천이나 커뮤니티 매칭 문제
- 이미 장소와 일정이 정해진 모임의 운영 문제
- 장기적인 인간관계 형성 자체의 문제

## 반증 조건

아래 중 하나가 확인되면 현재 문제 정의를 수정하거나 폐기합니다.

- 대상자 대부분이 10분 이내에 기존 방식으로 결정하며 불편이 작다.
- 모임 무산의 핵심 원인이 장소·교통·예산 조율이 아니라 참여 의지 부족이다.
- 제안자가 아니라 다른 참여자가 실제 의사결정권자다.
- AI 추천에 필요한 정보를 제공하는 부담이 기존 조율보다 크다.
- 충분한 품질의 장소·교통 데이터를 해커톤 범위에서 확보할 수 없다.

## 검증 질문

1. 가장 최근 4명 이상 모임을 제안한 때를 처음부터 끝까지 설명해 주세요.
2. 누구와 무엇을 결정해야 했고, 어떤 도구를 사용했나요?
3. 가장 오래 걸린 결정은 무엇이었나요?
4. 후보가 탈락한 실제 이유는 무엇이었나요?
5. 확정까지 메시지가 몇 번 오갔고 얼마나 걸렸나요?
6. 최근 취소되거나 미뤄진 모임이 있다면 어떤 과정이었나요?
7. 결정 과정에서 누가 가장 많은 일을 했나요?
