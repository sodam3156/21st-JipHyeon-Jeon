# 문제 정의 — 돌봄 집현전 (IDEA-002)

> `D-010`(2026-07-25, accepted)으로 선택됐습니다. Gate 2 정식 검증(이슈 #3)은 waived 상태이며, 아래 내용 중 `가설`로 표기된 항목은 아직 검증 결과가 아닙니다.

## 한 문장

세종에 거주하며 6–36개월 자녀를 가정양육하는 보호자가, 갑작스러운 평일 2–4시간 돌봄 공백에서 공식 시간제보육의 연령·시간·등록·신청 조건을 제때 확인하지 못해 다음 행동(신청 또는 전화)으로 넘어가지 못한다. (상태: 가설, HYP-002)

## 최근 실제 행동과 발생 빈도

이슈 #3(48시간 검증, 마감 2026-07-27) 결과 대기. 통과 기준: 보호자 6명 중 4명 이상이 최근 3개월 내 실제 사건을 구체적으로 재구성, 3명 이상이 두 개 이상 경로를 거치고도 핵심 정보 때문에 마감 전 결정을 못 함. (상태: 미정 — 검증 결과 없음)

## 현재 대안과 구체 실패 지점

- 현재 대안: 중앙/세종육아종합지원센터 시간제보육, 아이사랑 신청·예약 경로, 공공데이터포털 어린이집 정보 API를 각자 따로 확인
- 실패 지점(가설): 대상 연령·이용 자격, 운영 요일·시간, 예약 가능 시점·취소 규칙, 비용·지원시간, 자료 기준일 등이 기관·경로별로 흩어져 있어 결정 마감 전에 확인을 끝내지 못함

## 구조적 공급 부족과 소프트웨어가 줄일 수 있는 손실의 경계

- 줄이려는 손실: 정보·절차 단절로 인한 탐색·통화 시간, 반복 오문의, 결정 지연·포기
- 줄이지 않는 것(명시적 제외): 실제 시간제보육 자리 부족 자체, 실시간 잔여석·예약 성공 여부
- 원칙: 실시간 가용성을 확인할 공식 연동이 없으면 반드시 `확인 불가`로 남기고 기관으로 인계 (`docs/00_overview/OPPORTUNITY_MAP.md` OPP-005 안전 경계)

## 지지 근거·반박 근거·일반화 한계

- 지지: E-004·007·008, IN-001·006·007·009·017–019 (상태: 근거·인사이트, 사람 검토 전 — Gate 1 waived)
- 반박 후보: 최근 보호자 행동 근거 부재, 운영자 반복 오문의 근거 부재, 4명 이상에게 핵심 원인이 절대적 공급 부재로 확인될 경우 (이슈 #3 실패 기준)
- 일반화 한계: 세종 거주·6–36개월·평일·2–4시간이라는 대표 사건 하나로 좁힌 것이며 다른 연령·요일·시간대로 일반화하지 않음

## 반증 조건과 다음 검증

- 이슈 #3 실패 기준 충족 시(예: 대부분 기존 경로 하나로 10분 안에 해결, 실제 최근 사례 3명 미만) D-010 재검토
- 이슈 #4(공식 데이터 스파이크, 마감 2026-07-27) 결과로 확인 필드를 `공식 확인 가능/기관에 직접 확인/제공 금지`로 분류

## 해결책을 제외한 문제 범위

- 아동 이름·정확한 생년월일·상세주소·건강정보는 수집·저장하지 않음
