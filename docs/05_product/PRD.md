## 구체 고객·촉발 상황·현재 실패

세종 거주, 6–36개월 자녀를 가정양육하는 보호자가 갑작스러운 평일 2–4시간 돌봄 공백에서 공식 시간제보육의 조건·신청 경로를 제때 확인하지 못해 다음 행동으로 넘어가지 못한다. 상세: `planning.problem-definition`.

## 대표 사건과 목표 상태 변화

- 대표 사건: 6–36개월 자녀의 갑작스러운 평일 2–4시간 돌봄 공백
- 이전 상태 → 목표 상태: 조건·경로가 흩어져 결정 못 함 → 5분 안에 공식 다음 행동과 미확인 항목을 구분하고 신청·전화로 인계

## P0 · P1 · 제외 범위

- P0: 조건 입력 → 자격·정책 판정 → 돌봄 확보 실행카드 → 신청·전화 인계
- P1(후순위): 다국어, 알림·리마인드, 이력 저장
- 제외: 실시간 잔여석·예약 성공 주장, 시설 안전성·품질 순위, 비공식 돌보미 매칭, 의료·아동안전 판단, 아동 민감정보 수집·저장

## 사용자 스토리와 수용 기준

### US-001 조건 판정

보호자로서, 생활권·연령구간·희망 날짜/시간·긴급성·이동수단·아이사랑 등록 준비 여부를 입력하면, 공식 시간제보육 조건에 대한 일치/불일치/미확인 판정을 받고 싶다.

수용 기준:
- 입력 후 5분 안에 판정 결과가 나온다
- 미확인 항목은 `확인 불가`로 표기되고 기관 확인 경로가 함께 제시된다
- 실시간 잔여석·예약 성공을 주장하지 않는다

### US-002 실행카드 인계

보호자로서, 조건 판정 결과와 함께 연락 순서·체크리스트·전화 스크립트·공식 링크를 받아 바로 신청하거나 전화하고 싶다.

수용 기준:
- 모든 값에 공식 URL과 확인일이 표시된다
- 공식 상담창구·대체 경로가 함께 제시된다

## 데이터 출처·시점·결측·오류 계약

이슈 #4(공식 데이터 스파이크)로 중앙/세종육아종합지원센터 시간제보육, 아이사랑, 공공데이터포털 어린이집 API를 확인해 필드를 `공식 확인 가능/기관에 직접 확인/제공 금지`로 분류한다. 결측·오류 시 `확인 불가` + 공식 확인 경로. 상세 계약: `planning.solution-brief`.

## AI·규칙·사람의 책임과 승인 경계

AI는 입력 구조화와 설명만 담당하고, 규칙 엔진이 공개 자격·시간 조건을 판정하며, 보호자가 우선순위와 신청을 결정하고, 기관이 실제 자격·가용성·예약을 승인한다. 사람 검토 역할: `planning.solution-brief` 참조.

## 3분 발표 안의 90초 핵심 데모

입력(조건) → 판단(자격·정책·최신성) → 실행카드 출력 → 인계(신청/전화). 이슈 #4로 확인된 실제 공식 링크·확인일을 사용하고, LIVE/VERIFIED DATA/MOCK/ROADMAP을 화면에서 구분한다.

## timeout·429·형식 오류·stale data·오프라인 축소 모드

API 미승인·장애·오래된 데이터 시 확인일이 표시된 검증 fixture와 공식 deep-link + 전화 인계로 축소한다. 근거가 오래됐거나 충돌하면 결과를 확정하지 않는다.
